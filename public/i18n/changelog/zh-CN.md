## v1.4.0 (2026-10-10)

### ✨ 新增

- **API 密钥支持每日 Token 限额**：每个客户端 key 可设每日上限（如 100M/天），超限返回 429 `rate_limit_error`，服务器本地零点自动重置；Endpoint 页有全局总开关，每 key 随时增改限额，列表实时显示今日用量占比。
- **配额跟踪器卡片图标直达供应商官网**：配额页每张卡片左上角的供应商 logo 现在点击即在新标签页打开对应官网/控制台。
- **「隐藏零余额提供商卡片」开关**：实验页的卡片隐藏新增第二档——0 余额/0 积分的连接卡片可整卡隐藏，与既有「隐藏无配额卡片」互相独立、可叠加。
- **「待重新授权」账号状态**：OAuth 账号刷新令牌失效时，连接行亮起「待重新授权」标记并冷却 24 小时（不再每 2 分钟空撞一次）；重新授权立即恢复。
- **CodeBuddy 模型面对齐官方积分页**：国际线补上整条 Claude 线（Opus 5.5 / Sonnet 5.5 等 8 款）与 Grok-4.7、Gemini-3.8-Flash、GPT-6.1-Sol；国内线新增 GLM-5.3-FlashX（0.14x）与 StepFun Step-5-Preview（0.43x）；Space-Bunny 折扣结束回调 0.08x。新增「付费档」「订阅优先」两种模型徽章。
- **OpenCode / Token Harbor 新模型**：OpenCode 付费线补齐 Claude Haiku 5.5（能力声明修正为 1M）等新上架模型；Token Harbor 收录 `claude-haiku-5.5:free`。
- **Trae Free 模型目录对齐官方目录**（issue #54）：新增 18 款，移除 10 款已被上游下架的模型。
- **免费线卡片的 CreditDaddy 网关状态**（issue #49）：桌面 v1.3.5 修订资产已先行带上，本版起全渠道生效。
- **Release 资产命名平台化**：Windows / macOS / fnOS 安装包文件名统一为「软件名-平台-…」，同一 Release 页面内同平台资产自动聚类排序。

### 🐛 修复

- **combo 模型组的上下文窗口现在正确发给客户端**：此前组合条目只写嵌套能力块，客户端读不到顶层 `context_window` 只能按模型名猜、且往高猜，长上下文直到上游硬失败。
- **流式请求统计口径两处修正**：答复完整送达后客户端提前断开不再记成失败（issue #48 / #50）；上游中途掐断的干净结束不再记成成功，改记「截断」；SSE 流中被丢弃的损坏行会计数并显示在请求明细。
- **刷新令牌处理三连修**：轮换后的新令牌落库失败时立即报错，不再静默用旧令牌把账号整体踢下线；sql.js 模式落盘失败自动重排重试；401 自动刷新重试失败时把真实原因透传给客户端。
- **StepFun CN 实名闸门不再误报「额度用完」**：未完成实名核验的 403 不再把模型锁 2 分钟，仪表盘给出实名页直达链接，combo 立即穿透到下一候选。
- **GitHub Copilot 配额按类别分行**：chat / completions 月度窗口不再并入资源包合计，与 Antigravity 口径一致。
- **自定义连接名称优先显示**：连接行不再被用户名/邮箱挤掉自定义名称。
- **模型目录与能力参数纠错**：客户端拿到的上下文/输出上限对齐各供应商真实值（修复别名漂移、目录查找落空、combo 聚合缺口等同源问题）。
- **Windows 安装器三连修**：升级不再弹「无法关闭」、不再执行旧版卸载器；UAC 被拒绝不再无声失败。
- **fnOS 打包修复**：不再误覆盖 standalone 自带的精简 next 模块（装上即起不来的根因）。

## v1.3.5 (2026-10-05)

### ✨ 新增

- **免费线卡片新增 CreditDaddy 网关状态**（issue #49）：ZCode Free / MiniMax Free / Trae Free 卡片现在会探测本地网关端口并直观显示连通状态，不通时给出下载链接与开启引导。
- **新增 Trae Free 供应商（`trae-free`）**：经本地 CreditDaddy 网关使用 Trae（SOLO）远程 Agent 额度，与 ZCode Free / MiniMax Free 同款接线——免登录卡片、主机/端口共享、路径按线独立，12 款模型（Doubao Seed Code、MiniMax M2.7、GLM 5 系、DeepSeek V4 系、Kimi K2.5/2.6、Qwen 3.5/3.6），支持思考流；卡片图标为从客户端 exe 提取的官方黑白标。

### 🐛 修复

- **升级安装不再弹「无法关闭」（Windows 安装包已原位替换更新）**：升级时新安装器自带清理、跳过旧版本冻结的旧卸载器代码，不再触发幽灵进程的无法关闭弹窗或静默退出码 2，用户数据不受影响。
- **中途夭折的流式请求不再留下一条「绿色 0 token」的假成功**（issue #48）—— 流式请求一开就写入占位记录，但那时还没产出任何内容、状态却已是「成功」。上游随后断链时，中止路径完全不碰数据库，那行记录再没人修正：一次被掐断的请求会在详情列表里一直显示成「已完成、且恰好没花钱」。现在进行中的记录就显示为进行中，被中止的流式请求记为失败。
- **单个模型失败不再把整条连接标记为「不可用」**（issue #46）—— 这才是根因：按模型的锁在写入时，会连带写一个账号级的「不可用」标志，而选路自始至终只看那把按模型的锁。于是兄弟模型照常工作、连接却显示为宕机。现在这个标志只在真正的账号级失败时才写。
- **CreditDaddy 三条线的 404 不再被报成「模型不存在」**（issue #47）：CreditDaddy 已把网关端点迁到带品牌名的路径（`/gateway/zcode/…` 等），404 说的是端点而不是你的模型。现在提示会直说这一点，卡片上也给出排查指引：路径要保留品牌段；若 CreditDaddy 版本早于这次改名（仍只提供旧的裸端点），应升级 CreditDaddy 而不是改那个输入框。
- **部分受限的连接改为显示黄色，不再标红**（issue #46）：只有一个模型在冷却期的连接仍在正常服务其它模型，现在有独立的「部分受限」状态，不再被当成整个账号宕机。同时把原先手写了四份、彼此可能不一致的状态判定收敛成一份。
- **单个模型的额度用完不再显示成「账号不可用」**（issue #46）：Google / Antigravity 的额度按模型分桶，我们的锁也是按模型的，但提示一律写「该账号额度已用完」——而同一连接上的其它模型在整个窗口内照常可用。现在提示会点名具体模型并说明其余模型不受影响；真正整账号耗尽的情况文案不变。
- **用量「概览」不再空白、而「详情」列着一堆 0 token 的行**（issue #48）：两个页签读的是不同的表，上游没回 token 数时，一侧整行被丢掉、另一侧却照样写进去（显示 0 输入 / 0 输出）。此前只有流式请求有估算兜底，非流式请求没有。现在两个页签显示同一组估算出来的数字。估算值只记进仪表盘——客户端拿到的 usage 仍严格是上游返回的原值。
- **超长上下文自动压缩默认触发比例 0.9 → 0.95**：自动压缩改为更贴近窗口上限才触发（阈值档位与总开关不变，可在「实验特性」卡片调整）。
- **Claude Code / mirasim 不再在 160K 处强行压缩**：模型列表此前只按 OpenAI 约定上报窗口，Claude CLI 读不到就回退到内置的 20 万默认值，于是 Qwen3.8-Max（真实 100 万）等模型在客户端侧 16 万 token 就触发压缩。现在补发 Anthropic 约定的字段，客户端能读到真实窗口。
- **仪表盘模型卡不再把 1M 窗口显示成 20 万**：Qoder（`qd` / `qdc`）、Kiro（`kr`）、CodeBuddy CN（`cbcn`）、Antigravity（`ag`）这四条线的模型此前在仪表盘上因按别名查能力而跌到 20 万地板（vision / reasoning 徽章也被剥掉），Kiro 的 gpt-5.6 系窗口还虚高到 105 万。现已全部归一化到正确的 1M 档。
- **Trae Free 卡片图标不再缺图**：本版接入时漏了图标资源，卡片回落成文字缩写、而其它屏又是另一张（彩色）标。现已统一使用从客户端 exe 提取的 Trae（SOLO）官方黑白标。
- **Trae Free 的网关主机/端口设置生效**：本版接入时漏了一处代码位置，局域网主机与端口配置对 Trae Free 不起作用、请求仍打本机默认地址。已修复。
- **Qoder 订阅积分「凭空消失」有了明确提示**（issue #44）：CreditDaddy 同步来的网页会话失效时，套餐积分读不到却没有任何提示。现在额度卡片会直接警告会话已失效、并在导入连接时逐账号校验会话可用性点名失效账号。
- **Windows 升级安装不再卡在「10Router 无法关闭」**：旧版程序以管理员身份运行时（MITM 绑定 443 需要），普通权限的安装器杀不掉它。现在安装器会请求一次管理员授权来关闭旧进程；拒绝授权则退化为原行为，不会更糟。`10Router.Setup` 与 `10Router-Web-Setup` 均已覆盖。
- **桌面端更新下载加了超时保护**：网络异常挂起时更新流程不再永久卡死，失败会清理残留的临时文件。
