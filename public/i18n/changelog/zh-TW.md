# 更新日誌

這裡展示面向用戶的關鍵更新；完整開發明細見 [CHANGELOG.md](https://github.com/techysy/10router/blob/main/CHANGELOG.md)。

## v1.4.0 (2026-10-10)

### ✨ 新增

- **API 金鑰支援每日 Token 限額**：每個客戶端 key 可設每日上限（如 100M/天），超限回傳 429 `rate_limit_error`，伺服器本地零點自動重置；Endpoint 頁有全域總開關，每 key 隨時增改限額，列表即時顯示今日用量佔比。
- **配額追蹤器卡片圖示直達供應商官網**：配額頁每張卡片左上角的供應商 logo 現在點擊即在新分頁開啟對應官網/控制台。
- **「隱藏零餘額供應商卡片」開關**：實驗頁的卡片隱藏新增第二檔——0 餘額/0 積分的連接卡片可整卡隱藏，與既有「隱藏無配額卡片」互相獨立、可疊加。
- **「待重新授權」帳號狀態**：OAuth 帳號重新整理權杖失效時，連接列亮起「待重新授權」標記並冷卻 24 小時（不再每 2 分鐘空撞一次）；重新授權立即恢復。
- **CodeBuddy 模型面對齊官方積分頁**：國際線補上整條 Claude 線（Opus 5.5 / Sonnet 5.5 等 8 款）與 Grok-4.7、Gemini-3.8-Flash、GPT-6.1-Sol；國內線新增 GLM-5.3-FlashX（0.14x）與 StepFun Step-5-Preview（0.43x）；Space-Bunny 折扣結束回調 0.08x。新增「付費檔」「訂閱優先」兩種模型徽章。
- **OpenCode / Token Harbor 新模型**：OpenCode 付費線補齊 Claude Haiku 5.5（能力宣告修正為 1M）等新上架模型；Token Harbor 收錄 `claude-haiku-5.5:free`。
- **Trae Free 模型目錄對齊官方目錄**（issue #54）：新增 18 款，移除 10 款已被上游下架的模型。
- **免費線卡片的 CreditDaddy 閘道狀態**（issue #49）：桌面 v1.3.5 修訂資產已先行帶上，本版起全渠道生效。
- **Release 資產命名平台化**：Windows / macOS / fnOS 安裝包檔名統一為「軟體名-平台-…」，同一 Release 頁面內同平台資產自動聚類排序。

### 🐛 修復

- **combo 模型組的上下文視窗現在正確發給客戶端**：此前組合條目只寫嵌套能力區塊，客戶端讀不到頂層 `context_window` 只能按模型名猜、且往高猜，長上下文直到上游硬失敗。
- **流式請求統計口徑兩處修正**：答覆完整送達後客戶端提前斷開不再記成失敗（issue #48 / #50）；上游中途掐斷的乾淨結束不再記成成功，改記「截斷」；SSE 流中被丟棄的損壞行會計數並顯示在請求明細。
- **重新整理權杖處理三連修**：輪換後的新權杖落庫失敗時立即報錯，不再靜默用舊權杖把帳號整體踢下線；sql.js 模式落盤失敗自動重排重試；401 自動刷新重試失敗時把真實原因透傳給客戶端。
- **StepFun CN 實名閘門不再誤報「額度用完」**：未完成實名核驗的 403 不再把模型鎖 2 分鐘，儀表盤給出實名頁直達連結，combo 立即穿透到下一候選。
- **GitHub Copilot 配額按類別分行**：chat / completions 月度視窗不再併入資源包合計，與 Antigravity 口徑一致。
- **自訂連接名稱優先顯示**：連接列不再被使用者名稱/信箱擠掉自訂名稱。
- **模型目錄與能力參數糾錯**：客戶端拿到的上下文/輸出上限對齊各供應商真實值（修復別名漂移、目錄查找落空、combo 聚合缺口等同源問題）。
- **Windows 安裝器三連修**：升級不再彈「無法關閉」、不再執行舊版卸載器；UAC 被拒絕不再無聲失敗。
- **fnOS 打包修復**：不再誤覆蓋 standalone 自帶的精簡 next 模組（裝上即起不來的根因）。

## v1.3.5 (2026-10-05)

### ✨ 新增

- **免費線卡片新增 CreditDaddy 閘道狀態**（issue #49）：ZCode Free / MiniMax Free / Trae Free 卡片現在會探測本地閘道連接埠並直觀顯示連通狀態，不通時給出下載連結與開啟引導。
- **新增 Trae Free 供應商（`trae-free`）**：經本地 CreditDaddy 閘道使用 Trae（SOLO）遠端 Agent 額度，與 ZCode Free / MiniMax Free 同款接線——免登入卡片、主機/連接埠共享、路徑按線獨立，12 款模型（Doubao Seed Code、MiniMax M2.7、GLM 5 系、DeepSeek V4 系、Kimi K2.5/2.6、Qwen 3.5/3.6），支援思考流；卡片圖示為從客戶端 exe 提取的官方黑白標。

### 🐛 修復

- **升級安裝不再彈「無法關閉」（Windows 安裝包已原位替換更新）**：升級時新安裝器自帶清理、跳過舊版本凍結的舊解除安裝器程式碼，不再觸發幽靈程序的無法關閉彈窗或靜默退出碼 2，用戶資料不受影響。
- **中途夭折的串流請求不再留下一條「綠色 0 token」的假成功**（issue #48）—— 串流請求一開就寫入佔位記錄，但那時還沒產出任何內容、狀態卻已是「成功」。上游隨後斷鏈時，中止路徑完全不碰資料庫，那列記錄再沒人修正：一次被掐斷的請求會在詳情列表裡一直顯示成「已完成、且恰好沒花錢」。現在進行中的記錄就顯示為進行中，被中止的串流請求記為失敗。
- **單一模型失敗不再把整條連線標記為「不可用」**（issue #46）—— 這才是根因：按模型的鎖在寫入時，會連帶寫一個帳號級的「不可用」標誌，而選路自始至終只看那把按模型的鎖。於是兄弟模型照常工作、連線卻顯示為停擺。現在這個標誌只在真正的帳號級失敗時才寫。
- **CreditDaddy 三條線的 404 不再被報成「模型不存在」**（issue #47）：CreditDaddy 已把閘道端點遷到帶品牌名的路徑（`/gateway/zcode/…` 等），404 說的是端點而不是你的模型。現在提示會直說這一點，卡片上也給出排查指引：路徑要保留品牌段；若 CreditDaddy 版本早於這次改名（仍只提供舊的裸端點），應升級 CreditDaddy 而不是改那個輸入框。
- **部分受限的連線改為顯示黃色，不再標紅**（issue #46）：只有一個模型在冷卻期的連線仍在正常服務其它模型，現在有獨立的「部分受限」狀態，不再被當成整個帳號停擺。同時把原先手寫了四份、彼此可能不一致的狀態判定收斂成一份。
- **單一模型的額度用完不再顯示成「帳號不可用」**（issue #46）：Google / Antigravity 的額度按模型分桶，我們的鎖也是按模型的，但提示一律寫「該帳號額度已用完」——而同一連線上的其它模型在整個視窗內照常可用。現在提示會點名具體模型並說明其餘模型不受影響；真正整帳號耗盡的情況文案不變。
- **用量「概覽」不再空白、而「詳情」列著一堆 0 token 的列**（issue #48）：兩個頁籤讀的是不同的表，上游沒回 token 數時，一側整列被丟掉、另一側卻照樣寫進去（顯示 0 輸入 / 0 輸出）。此前只有串流請求有估算後備，非串流請求沒有。現在兩個頁籤顯示同一組估算出來的數字。估算值只記入儀表板——客戶端拿到的 usage 仍嚴格是上游回傳的原值。
- **超長上下文自動壓縮預設觸發比例 0.9 → 0.95**：自動壓縮改為更貼近視窗上限才觸發（閾值檔位與總開關不變，可在「實驗特性」卡片調整）。
- **Claude Code / mirasim 不再在 160K 處強制壓縮**：模型清單此前只按 OpenAI 約定上報視窗，Claude CLI 讀不到就回退到內建的 20 萬預設值，於是 Qwen3.8-Max（真實 100 萬）等模型在客戶端側 16 萬 token 就觸發壓縮。現在補上 Anthropic 約定的欄位，客戶端能讀到真實視窗。
- **儀表板模型卡不再把 1M 視窗顯示成 20 萬**：Qoder（`qd` / `qdc`）、Kiro（`kr`）、CodeBuddy CN（`cbcn`）、Antigravity（`ag`）這四條線的模型此前在儀表板上因按別名查能力而跌到 20 萬地板（vision / reasoning 徽章也被剝掉），Kiro 的 gpt-5.6 系視窗還虛高到 105 萬。現已全部歸一化到正確的 1M 檔。
- **Trae Free 卡片圖示不再缺圖**：本版接入時漏了圖示資源，卡片回落成文字縮寫、而其它屏又是另一張（彩色）標。現已統一使用從客戶端 exe 提取的 Trae（SOLO）官方黑白標。
- **Trae Free 的閘道主機/連接埠設定生效**：本版接入時漏了一處程式碼位置，區域網路主機與連接埠設定對 Trae Free 不起作用、請求仍打本機預設位址。已修復。
- **Qoder 訂閱積分「憑空消失」有了明確提示**（issue #44）：CreditDaddy 同步來的網頁工作階段失效時，套餐積分讀不到卻沒有任何提示。現在額度卡片會直接警告工作階段已失效，並在匯入連線時逐帳號校驗工作階段可用性點名失效帳號。
- **Windows 升級安裝不再卡在「10Router 無法關閉」**：舊版程式以管理員身分執行時（MITM 綁定 443 需要），一般權限的安裝器殺不掉它。現在安裝器會要求一次管理員授權來關閉舊行程；拒絕授權則退化為原行為，不會更糟。`10Router.Setup` 與 `10Router-Web-Setup` 均已涵蓋。
- **桌面版更新下載加了逾時保護**：網路異常掛起時更新流程不再永久卡死，失敗會清理殘留的暫存檔。

## v1.3.0 (2026-10-01)

### ✨ 新增

- **CLI 工具「模型組合方案」（Claude 卡，#17）**：Claude 工具卡新增 Profiles 欄，支援將 Opus/Sonnet/Haiku 映射、API Key 與上下文視窗儲存為多套命名方案；下拉切換即自動寫入 `~/.claude/settings.json`，無需再點 Apply，體驗無縫對標 CC-Switch。設定由伺服器端統一持久化，NAS、Tailscale 或通道存取時共享同一份設定。
- **配額視覺化重構：QuotaToolbar 與配額視窗時間線**：用量頁引入響應式配額工具列與週期視窗時間線（`QuotaWindowTimeline`），直觀呈現各供應商週/月週期的額度重設與倒數計時；頂部增加「卡片」與「配額視窗」檢視切換（工作階段級記憶體保持，重新整理恆定預設展示卡片，不污染 localStorage）。多包分段進度條全面對齊 CreditDaddy 視覺語意，並支援卡片頂部展示精確最近到期時間。
- **全新搜尋與擷取供應商 TinyFish 與 Keenable（#26）**：
  - **TinyFish**（免費層）：全自動支援 Web Search 與 Web Fetch，官方任意餘額免扣費，免設定開箱即用；
  - **Keenable**（標準 API Key）：支援即時/專業模式搜尋，以及帶 `live=true` 的高保真任意網頁擷取；
  - 媒體提供商頁面（Web Search / Web Fetch）及 `/v1/search`、`/v1/web/fetch` 介面全線接入。
